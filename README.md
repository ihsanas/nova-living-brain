# NOVA//FREQ Living Brain 3D

Dashboard publik pengembangan NOVA. Angka kesiapan bersifat ilustratif, bukan IQ atau benchmark terverifikasi.

## Deploy
Unggah `index.html` dan folder `data/` ke branch `main`. Aktifkan GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

## Pembaruan
Edit `data/progress.json` dan commit perubahan. Halaman membaca ulang data setiap 60 detik, sesudah deploy GitHub Pages selesai.

## Protokol iterasi wajib
Hipotesis → Rancang → Uji → Evaluasi → Revisi → Uji ulang → Catat bukti. Tidak boleh menaikkan status G0/G1 ke G2/G3 tanpa persetujuan dan bukti yang memadai.

Jangan unggah audio privat, arsip Living Brain internal, identitas pribadi, atau rahasia akses ke repository publik.
